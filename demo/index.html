LAVERTYCase Reader

Read your own file

Choose a scanned Arabic case file: a PDF of up to 6 pages, or a page image. The Case Reader finds the stamps, signatures and handwriting, reads every page and checks the citations. It takes one to three minutes.

Use only fictional or public documents. The file is sent to Meta's Muse Spark and SAM 3.1 through the Meta Model API to be read, and the Case Reader keeps nothing.
